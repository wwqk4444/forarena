# KRIPTOGRAM 题解（COCI 2011/2012 · 第 4 轮 · 第 6 题）

> 题目来源：**COCI 2011/2012, 4th round, task KRIPTOGRAM**，作者 Goran Žužić，满分 140 分。
> 时间限制 1 s，内存限制 64 MB。（DMOJ 题号 `coci11c4p6`）

---

## 1. 题意

Mirko 截获了一条加密消息。他只知道：**某一句已知的句子（原文中的连续若干词）一定出现在原文里**。

加密方式是**逐词替换**：

- 原文中每个词都被替换成某个词（可以替换成它自己）；
- 同一个词在原文中多次出现，每次都被替换成**同一个**词（替换是"一致"的）；
- 不同的词不会被替换成同一个词（替换是**单射**的）。

给出加密后的消息（一行，单词之间恰好一个空格，行尾用 `$` 结束，`$` 不算消息内容）和那句已知的句子（格式相同），求**这句句子在加密消息中第一次出现的起始词的下标（从 1 开始）**。保证一定有解。

输入规模：两行都不超过 $10^6$ 个字符。

### 样例

| 输入 | 输出 |
|---|---|
| `a a a b c d a b c $`<br>`x y $` | `3` |
| `xyz abc abc xyz $`<br>`abc abc $` | `2` |
| `a b c x c z z a b c $`<br>`prvi dr prvi tr tr x $` | `3` |

---

## 2. 关键观察：只需要"相同 / 不同"的结构

我们不认识原文的任何一个词，但**词的具体内容无关紧要**，真正有用的信息是：**哪些位置上的词是同一个词，哪些不是**。

**定义（同构 / 相同关系矩阵）** 对两个等长的词序列 $X[1..m]$、$Y[1..m]$，称它们**同构**，当且仅当对任意 $1 \le k < l \le m$ 都有

$$X[k] = X[l] \iff Y[k] = Y[l].$$

**引理 1（可解密性的等价刻画）** 消息中从第 $s$ 个词开始、长为 $m$ 的窗口能够"是"已知句子 $B[1..m]$（即存在一个逐词替换把 $B$ 变成该窗口），当且仅当该窗口与 $B$ **同构**。

**证明**

- （$\Rightarrow$）若存在替换 $\varphi$ 使 $A[s+k-1] = \varphi(B[k])$：
  若 $B[k]=B[l]$，则 $A[s+k-1]=A[s+l-1]$；若 $B[k]\ne B[l]$，由 $\varphi$ 单射得 $A[s+k-1]\ne A[s+l-1]$。故同构。
- （$\Leftarrow$）若同构，定义 $\varphi(B[k]) := A[s+k-1]$。
  - **良定义**：$B[k]=B[l] \Rightarrow A[s+k-1]=A[s+l-1]$，即同一个词不会有两个像。
  - **单射**：$B[k]\ne B[l] \Rightarrow A[s+k-1]\ne A[s+l-1]$，不同的词像不同；由同构可知窗口出现的不同词个数等于 $B$ 中不同词个数，所以在两边的词集上这已经是一个双射。
  - 原文中除这句话以外的词 Mirko 本来就不知道，可以任意选取，因此这个局部双射总能扩充成原文到整个密文的双射。$\blacksquare$

于是问题变成：**在密文词序列中找第一个与句子同构的连续窗口**。这已经不是普通字符串匹配了，但可以按下面办法"线性化"。

### 上次出现位置（距离）编码

对序列 $X[1..m]$ 定义编码

$$d_X[i] = \begin{cases} i - j, & j = \max\{j' < i : X[j'] = X[i]\} \text{ 存在}\\[2pt] \infty, & \text{否则}\end{cases}$$

即"与上一个相同词的距离"，没有出现过就是 $\infty$。

**引理 2** 两个等长序列 $X,Y$（长 $m$）同构 $\iff$ 对每个 $k \in [1,m]$ 有

$$\min\bigl(d_X[k],\, k\bigr) \;=\; \min\bigl(d_Y[k],\, k\bigr).$$

$\min(d,k)$ 的作用是**把窗口外的信息截断**：若 $d_X[k] < k$，说明上一个相同的词还在窗口内，重复关系是"真的"；若 $d_X[k] \ge k$，说明窗口内 $k$ 位置之前没有出现过这个词，对窗口的观察者而言它就是"首次出现"。

**证明（归纳）** 记 $e_X(k)=\min(d_X[k],k)$。下面对 $k$ 归纳：假设前 $k-1$ 个位置的相同关系矩阵完全一致。此时 $k$ 位置与前 $k-1$ 个位置是否相等：

- 若 $e_X(k) = e_Y(k) = r < k$，则 $X[k]$ 与窗口内第 $k-r$ 个位置相同，而由归纳假设 $k-r$ 这个位置在两个序列里属于"同一类"，故 $k$ 在两个序列里也落在对应的同一类中，关系矩阵延长后仍一致；
- 若 $e_X(k)=e_Y(k)=k$（即 $d \ge k$），则 $k$ 位置是一个**新词**，两边同时引入新类，关系矩阵仍一致。

反过来，若同构，则"$k$ 位置与前面哪个位置相等"两边一致，故 $e_X(k)=e_Y(k)$。$\blacksquare$

> ⚠️ **易错点**：这里必须用"**在窗口内**的上次出现位置"，即必须写 $\min(d,k)$ 做截断。如果直接比较整个序列的 $d$ 值，会用到窗口之外的词——例如密文 `a b a`、句子 `x y`：第 3 个词 `a` 在整条消息里出现过，但对这个长度 2 的窗口来说是"新词"。

## 3. 算法：改造 KMP

把序列换成编码 $e(\cdot)$ 之后，问题几乎就是普通的模式匹配，唯一区别是：**模式位置 $k$ 的"截断参数"依赖匹配到的前缀长度 $k$**，也就是匹配的判定要写成

$$\text{eq}(k, i) := \Bigl[\min\bigl(d_T[i],\, k\bigr) = \min\bigl(d_B[k+1],\, k\bigr)\Bigr]$$

含义：当前已经匹配了模式的前 $k$ 个词（于是窗口长度是 $k$，第 $k+1$ 个位置是检验对象），文本第 $i$ 个位置是否能接在这段前缀后面。

只要 $\text{eq}$ 只依赖 $k$（前缀长度）和当前字符 $i$，KMP 的全部推理都原样成立（失败后回退到 $fail[k]$，仍然只依赖已经匹配的前缀），所以直接照抄 KMP：

1. 求模式 $B$ 的前缀函数 $fail[1..m]$：
   $$fail[i+1] = \max\{L < i+1 : B[1..L] \text{ 与 } B[i-L+1..i] \text{ 同构}\}$$
2. 扫描文本，维护当前匹配长度 $k$，失配时 $k \leftarrow fail[k]$，匹配满 $m$ 即找到第一次出现，答案是 $i-m+2$（转成 1 开始的下标）。

因为 $e_B(k)$ 是**前缀的函数**（前缀函数本质就是"模式与自身的一个后缀同构"），一样的 $\text{eq}$ 直接复用即可。

**复杂度**：编码用哈希表，期望 $O(n+m)$ 时间、$O(n+m)$ 空间；KMP 部分严格 $O(n+m)$。

### 参考代码（C++17）

```cpp
// COCI 2011/2012, 4. kolo, task KRIPTOGRAM
#include <bits/stdc++.h>
using namespace std;

struct Line {
    string buf;                       // 拥有所有字符
    vector<string_view> word;         // 指向 buf 的切片
};

static Line readLine(istream &in) {
    Line L;
    getline(in, L.buf);
    size_t i = 0, n = L.buf.size();
    while (i < n) {
        if (L.buf[i] == '$') break;                    // '$' 表示行结束
        if (L.buf[i] == ' ') { ++i; continue; }
        size_t j = i;
        while (j < n && L.buf[j] != ' ' && L.buf[j] != '$') ++j;
        L.word.emplace_back(L.buf.data() + i, j - i);
        i = j;
    }
    return L;
}

// d[i] = 与上一个相同词的距离，没有则为 INF
static vector<int> encode(const vector<string_view> &w) {
    const int INF = INT_MAX / 2;
    vector<int> d(w.size(), INF);
    unordered_map<string_view, int> last;
    last.reserve(w.size() * 2 + 1);
    for (int i = 0; i < (int)w.size(); ++i) {
        auto it = last.find(w[i]);
        if (it != last.end()) d[i] = i - it->second;
        last[w[i]] = i;
    }
    return d;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    Line text = readLine(cin), pat = readLine(cin);
    int n = text.word.size(), m = pat.word.size();
    if (m == 0) { cout << 0 << '\n'; return 0; }

    vector<int> a = encode(text.word), b = encode(pat.word);

    // 已匹配模式前缀长度 j，文本第 i 个位置能否接上
    auto eq = [&](int j, const vector<int> &txt, int i) {
        int cap = j + 1;                                    // 窗口内部长度
        return min(txt[i], cap) == min(b[j], cap);
    };

    vector<int> fail(m + 1, 0);                             // 模式的 KMP 前缀函数
    for (int i = 1, k = 0; i < m; ++i) {
        while (k > 0 && !eq(k, b, i)) k = fail[k];
        if (eq(k, b, i)) ++k;
        fail[i + 1] = k;
    }

    int answer = 0;                                         // 题目保证有解
    for (int i = 0, k = 0; i < n; ++i) {
        while (k > 0 && !eq(k, a, i)) k = fail[k];
        if (eq(k, a, i)) ++k;
        if (k == m) { answer = i - m + 2; break; }          // 1 开始的下标
    }
    cout << answer << '\n';
    return 0;
}
```

> 也可用 `vector<string>` 直接存词（文件 `sol.cpp`），写法更直观；本文件 `sol_lean.cpp` 用"一块缓冲区 + `string_view`"，把 64 MB 内存限制下更稳（同样规模下峰值内存约从 40 MB 降到 18 MB）。

## 4. 样例验证

**样例 1** `a a a b c d a b c` / `x y`

句子的编码是 $[\infty,\infty]$（两个不同的词）。从第 1 个词起的窗口 `a a` 编码为 $[1,1]$，第 2 个窗口同理；第 3 个窗口 `a b` 编码为 $[\infty,\infty]$，同构 → 答案 **3**。

**样例 2** `xyz abc abc xyz` / `abc abc`

句子编码 $[\infty,1]$。窗口 `xyz abc` 编码 $[\infty,\infty]$ ✗；窗口 `abc abc` 编码 $[\infty,1]$ ✓ → 答案 **2**。

**样例 3** `a b c x c z z a b c` / `prvi dr prvi tr tr x`

句子结构是 `1 2 1 3 3 4`（第 3 个词 = 第 1 个词，第 5 个词 = 第 4 个词），编码 $[\infty,\infty,2,\infty,1,\infty]$。

- 从第 1 个词起：`a b c x c z` → $[\infty,\infty,\infty,\infty,2,\infty]$ ✗（第 3 个词不同）
- 从第 2 个词起：`b c x c z z` → $[\infty,\infty,\infty,2,1,1]$ ✗
- 从第 3 个词起：`c x c z z a` → $[\infty,\infty,2,\infty,1,\infty]$ ✓

→ 答案 **3**。

三个样例本仓库代码输出均为 `3, 2, 3` ✓。

## 5. 正确性总结

设算法返回窗口起点 $s$。

- **不会漏解**：KMP 扫描过程中，$k$ 恰好等于"以当前位置结尾的、与模式某个前缀同构的最长后缀长度"。当 $k=m$ 时，由 §2 的引理 1，该窗口确实是合法出现；第一次达到 $k=m$ 的位置必然是最小的 $s$，故不漏。
- **不会错报**：每次 $k$ 增加都经过 $\text{eq}$ 检验，而由引理 2，$\text{eq}$ 在"前 $k$ 个位置已同构"的前提下等价于"窗口延长一个词后仍同构"（归纳假设：$k$ 的增长过程始终保持同构）。所以输出的窗口一定同构。

## 6. 复杂度

| 项目 | 复杂度 |
|---|---|
| 编码（哈希表） | 期望 $O(n+m)$ |
| KMP 求前缀函数 + 扫描 | $O(n)$，均摊 |
| 总时间 | **期望 $O(n+m)$** |
| 空间 | $O(n+m)$ |

实测（本仓库 `sol_lean.cpp`，$10^6$ 字符级别数据）：

- 三个样例：立即通过；
- 极限数据（单行 988 001 字符，13.6 万个互不相同的词）：**87 ms / 18.3 MB**；
- 全扫描 + 大量 KMP 回退的构造数据：**57 ms / 28.1 MB**；
- 随机对拍 **3000 组**；小数据穷举（文本长度 ≤ 7、句子长度 ≤ 5、字母表 $\{a,b\}$ 的**全部**组合）**15 748 组** —— 全部与 $O(nm)$ 暴力一致。

## 7. 坑点清单

1. **下标从 1 开始**（样例 1 的答案是 3，不是 2）。
2. **行尾 `$`** 不属于消息；两行都要按同样规则解析。
3. **不要用全局的上次出现位置** \(d\) 直接比较（第 2 节的易错点），必须 $\min(d,\text{窗口内位置})$ 截断。
4. 单词可能很长（最多 $10^6$ 字符），不要按"每个字符一个节点"建模，按**词**为单位。
5. 句子长度为 1、消息只有一个词等边界要能跑通。
6. 64 MB 内存：$10^6$ 字符的输入 + 哈希表要省着用（`string_view` + 单缓冲区）。

## 8. 其它可行思路（了解即可）

- **官方题解**：定义 $\text{matches}(A[x,x+L], B[y,y+L])$ 为上文"同构"，用同样的 KMP 改造（与本文思路一致），编码 $T(X)[i]$ 就是本文的 $d$。
- **字符串哈希 / Rabin–Karp**：把"窗口内每个词的首次出现距离"作为窗口指纹，可以 $O(n)$ 预处理 + 双指针比较，但因为截断与窗口起点有关，实现比 KMP 麻烦。
- **后缀数组 + LCP**：把每个词替换成 $d$ 值后再处理"截断"问题，可用 $O((n+m)\log)$ 解决，但常数更大。
